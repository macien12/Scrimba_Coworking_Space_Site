# WeBarelyWork - Coworking Space Site

A simple project built for Scrimba to practice fundamental CSS layout and positioning concepts.

## What this project covers:

- **CSS Positioning**: Practicing `relative`, `absolute`, and `fixed` positioning (e.g. image banner badges and the floating chat button).
- **Element Alignment**: Learning how to position and align elements inside a layout, such as aligning navigation items to the left in the header (with Flexbox and auto-margins).
